FOTO DELLE CAMERE
=================

Metti qui le foto di ogni camera, in una sottocartella per camera.
Il nome della sottocartella e' il NUMERO della camera (quello mostrato
nella pagina di dettaglio, es. "Camera 101").

Esempio:
    static/images/camere/101/foto1.jpg
    static/images/camere/101/camera-matrimoniale.png
    static/images/camere/102/salotto.webp

Note:
- Estensioni supportate: .jpg .jpeg .png .gif .webp
- Le foto vengono mostrate nel dettaglio camera (/camere/{id}) in ordine alfabetico.
- Non serve modificare il database: basta aggiungere i file.
- Dopo aver aggiunto/rimosso foto, ricostruisci e riavvia l'applicazione
  (i file vengono serviti dalla cartella static compilata).
- Usa nomi di file semplici (senza spazi) per evitare problemi negli URL.
