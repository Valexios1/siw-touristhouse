FOTO DELLA HOME
===============

Metti qui le foto da mostrare nella pagina iniziale (/).
Vengono visualizzate in una galleria: la prima (in ordine alfabetico)
occupa tutta la larghezza come immagine di copertina.

Esempio:
    static/images/home/01-esterno.jpg
    static/images/home/02-camera.jpg
    static/images/home/03-colazione.png

Note:
- Estensioni supportate: .jpg .jpeg .png .gif .webp
- Non serve modificare il database: basta aggiungere i file.
- Dopo aver aggiunto/rimosso foto, ricostruisci e riavvia l'applicazione.
- Usa nomi di file semplici (senza spazi) per evitare problemi negli URL.
